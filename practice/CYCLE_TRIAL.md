# 첫 사이클 연습: 소규모 시설 예약 서비스

합성 데이터로 작업 사이클을 익히는 예제입니다. 실제 운영 데이터는 사용하지 않습니다.

목표: 사용자는 예약을 만들고 자신의 예약을 조회·취소합니다. 관리자는 전체 예약을 조회합니다.

첫 사이클 범위:
- 시설 한 곳, 시작·종료 시각을 가진 예약을 저장합니다.
- 종료 시각은 시작 시각보다 뒤여야 합니다.
- 같은 시설의 겹치는 예약은 거부합니다. 끝나는 시각과 다음 시작 시각이 같은 경우는 허용합니다.
- 사용자·관리자 화면을 구분하고 서버에서도 권한을 확인합니다.
- 일반 사용자는 다른 사용자의 예약을 취소할 수 없습니다.
- 저장 후 재조회할 수 있습니다.

시각 형식·시간대·사용자 인증 방법은 먼저 정하고 근거를 기록합니다. 데모용 계정이면 그 한계를 표시합니다. 클라이언트가 마음대로 보낸 역할명만 믿지 않습니다.

완료 확인:
1. 정상 예약 → 저장·재조회 성공.
2. 종료가 시작보다 빠른 예약 → 거부.
3. 겹치는 예약 → 거부.
4. 사용자 권한으로 관리자 조회 → 거부.
5. 다른 사용자 예약 취소 → 거부.
6. explainer 실제 호출·설명 문서 갱신·사용자에게 요약 전달.

첫 사이클이 끝나면 대화에서 설명 방식에 대한 의견을 전달합니다. 미구현은 미구현으로 표시합니다.
