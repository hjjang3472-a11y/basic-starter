| V-01 | 미정 | 미수행 | 미정 | 미정 | 미관찰 | 미실행 | 없음 |

## 중요한 확인 후보
실제 요구사항과 위험에 맞는 항목만 선택합니다.
- 정상 입력과 잘못된 입력
- 일반 사용자의 관리자 API 접근·다른 사용자 데이터 접근
- 저장 후 재조회·재실행 시 유지
- 중복 요청과 부분 저장 실패
- 계산 결과의 필수 조건 충족·계산 실패 처리
- 외부 연동 지연·실패
- 화면 조작과 API 결과의 일치

## 서버·화면 검증 구분
웹 서비스가 있는 경우에만 적용합니다. 실행 명령·포트·경로 등 재현 정보는 RUN에 기록합니다.

| 확인 단계 | 남길 증거 | 판정 범위 |
|---|---|---|
| 서버 기동·수신 | 실행 로그, 실제 수신 주소·포트, 프로세스 상태 | 서버가 대기 중인지 |
| 내부 HTTP 요청 | 실행 명령, 상태 코드·실제 응답, 기대값 | 해당 경로가 내부에서 응답하는지 |
| 미리보기 화면 | 실제 확인자·조작·관찰 결과 | 플랫폼 Browser에서 화면이 표시되는지 |
| 핵심 기능 | 입력·클릭·저장·조회 등 실제 요구사항의 기대값과 관찰값 | 사용자 기능이 동작하는지 |

내부 HTTP 응답만 확인했으면 미리보기와 클릭 동작은 미검증으로 남깁니다. 404는 응답한 서버의 경로를, 500은 서버 오류를 조사해야 하므로 연결 거부와 구분합니다. 원인 추정만으로 원인 확정이나 수정 완료라고 기록하지 않습니다.
