# 쉬운 진행 설명

아직 실제 서비스 작업 사이클을 수행하지 않았습니다. 아래 양식을 주요 작업 단위로 채웁니다.

## 현재 상태
- 완료: 준비 양식 배치
- 미확인: 실제 요구사항·서비스 동작·subagent 호출
- 다음: 프로젝트 확인과 첫 작업 계획

## 작업별 설명 양식
### 작업 ID / 작업 이름
1. **해결하려던 문제:** 사용자에게 어떤 불편·위험이 있었는가?
2. **구현한 동작:** 입력 → 처리 → 저장 → 화면 순서로 무엇이 일어나는가?
3. **선택 이유:** 왜 이 방법을 골랐으며 어떤 대안을 비교했는가?
4. **책임의 위치:** 어떤 모듈·함수가 어떤 규칙을 책임지는가?
5. **실제 확인:** 누가 어떤 방법으로 무엇을 관찰했는가? VERIFY의 어느 항목인가?
6. **장애와 한계:** 어디서 이상을 발견하고 어떻게 대응하며 아직 무엇을 모르는가?
7. **관련 근거:** 코드 위치·결정 ID·검증 ID.

### 쉬운 용어 풀이
- 용어 / 쉬운 뜻 / 이 기능에서의 예

### 설계 변경 이력
- 이전 선택 → 현재 선택 / 변경한 근거
