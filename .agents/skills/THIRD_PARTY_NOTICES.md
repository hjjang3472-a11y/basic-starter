# 각색 출처와 라이선스

이 키트의 starter-* 스킬은 아래 공개 지침의 아이디어와 절차를 기존 문서 체계에 맞게 한국어로 간추려 각색했습니다. 원문 전체 스킬 묶음이나 실행 도구를 포함하지 않습니다.

| 원문 저장소·확인 버전 | 참고한 스킬 | 적용·변경 내용 |
|---|---|---|
| [Matt Pocock skills](https://github.com/mattpocock/skills/tree/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d) | grill-with-docs, domain-modeling, to-tickets, tdd, code-review | 요구사항·작업 분할·행동 테스트·검토. 외부 트래커·필수 병렬 호출 대신 현재 SPEC·PLAN과 역할을 활용 |
| [Superpowers](https://github.com/obra/superpowers/tree/22f0b463e7a5e579904dd6211a520321035526f7) | systematic-debugging, verification-before-completion | 원인 확인과 완료 전 실제 증거. 전체 플러그인·워크트리·에이전트 하네스는 포함하지 않음 |
| [Addy Osmani agent-skills](https://github.com/addyosmani/agent-skills/tree/301b02b12bff98e4688e6984af6556802322bbde) | documentation-and-adrs | 판단·대안·결과·한계 기록. 별도 ADR 대신 기존 양식 우선 |

검토한 원문에 대한 라이선스 고지를 아래에 보존합니다. 이 고지는 제3자 자료의 고지이며 기존 저장소 전체의 라이선스를 변경하지 않습니다.
