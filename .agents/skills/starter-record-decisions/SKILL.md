# 선택 이유와 확인 결과를 기록하기

과제에서 지정한 양식·필수 파일명을 먼저 따른다. 같은 역할의 기존 문서가 있으면 활용하며 별도 ADR 파일 생성을 강제하지 않는다.

1. 결과에 영향을 주는 선택만 고른다. 사소한 편집마다 기록을 늘리지 않는다.
2. PLAN에 “선택한 판단 / 이유와 비교 대안 / 근거 / 한계·변경 조건”을 기록한다. 사용자 결정, AI의 제안, 확인된 사실과 가정을 구분한다.
3. 실제 검증 명령·조작, 기대·관찰 결과, 실패·미실행은 VERIFY에 기록하고 해당 선택과 연결한다. 참고 문서를 읽었다는 사실만으로 기능이 검증됐다고 쓰지 않는다.
4. EXPLAIN 또는 지정 제출 문서에 판단·근거·검증 결과·남은 한계와 영향을 쉬운 말로 요약한다. 사실보다 좋게 꾸미거나 없는 실험·이력을 만들지 않는다.
5. 선택이 바뀌면 이전 이유와 변경 근거를 짧게 남기고 현재 코드·실행 안내와 문서를 맞춘다.

선택번호(D-01 등)는 AI가 기록을 연결하기 위해 관리하는 표시다. 사용자가 번호를 붙이거나 외울 필요는 없다. 역할을 나눴다면 담당 파일만 수정하고 기록할 근거를 문서 담당에게 인계한다. 단독 진행은 같은 순서로 직접 기록하되 독립 검토가 있었다고 쓰지 않는다.
