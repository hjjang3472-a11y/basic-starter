# 문서형 스킬 사용 안내

이 키트에는 작업 단계별 지침인 문서형 스킬 7개가 있습니다. 스킬 파일을 읽는 데 별도 프로그램·API 키·MCP는 필요하지 않습니다. 기능 구현에 필요한 프로젝트의 기존 도구는 별개입니다.

## 어떤 때 사용하는가

| 스킬 이름 | 사용 시점 | 주로 남기는 근거 |
|---|---|---|
| starter-clarify-requirements | 목표·업무 규칙·완료 기준이 모호할 때 | SPEC의 요구사항·가정·확인 방법 |
| starter-plan-tasks | 일을 작은 단위로 나누고 순서·시간을 정할 때 | PLAN의 작업·운영 방식·시간 배분 |
| starter-test-behavior | 핵심 기능 구현·수정 전에 검사를 정할 때 | 재현 입력·기대값·실제 실행 결과 |
| starter-debug | 오류·연결 실패의 원인을 조사할 때 | 증상·가설·확인한 원인·재검증 |
| starter-review | 변경이 요구사항을 충족하는지 검토할 때 | 위치·재현 조건·영향이 있는 문제 |
| starter-verify-completion | 완료·수정 성공·제출 준비를 보고하기 전 | 현재 파일·명령·관찰값·남은 미확인 |
| starter-record-decisions | 중요한 선택과 제출 설명을 정리할 때 | 판단·이유·비교 대안·검증·한계 |

스킬은 AI의 작업 지침입니다. 7개를 순서대로 매번 실행하거나 7명의 에이전트를 만드는 도구가 아닙니다. 필요한 단계에 해당하는 것만 사용합니다.

## 호출과 인식

스킬은 대상 프로젝트의 `.agents/skills/<이름>/SKILL.md`에 둡니다. 저장소를 다른 폴더에 clone한 것만으로 현재 프로젝트에서 자동 발견된다고 가정하지 않습니다. [적용 요청문](../prompts/START_CYCLE.md) 또는 `tools/install_kit.py`로 필요한 파일을 적용하고 **실제 작업할 프로젝트 폴더**를 Codex에서 엽니다.

스킬을 지원하고 실제로 인식한 Codex에서는 `/skills` 목록으로 선택하거나 `$스킬이름`으로 요청할 수 있습니다. 예:

```text
$starter-clarify-requirements 이 과제의 필수 조건과 완료 기준을 정리해 줘.
$starter-plan-tasks 남은 시간 안에 필수 기능부터 구현할 계획을 세워 줘.
$starter-debug 서버가 열리지 않는 원인을 로그와 실제 포트부터 확인해 줘.
$starter-verify-completion 완료했다고 말하기 전에 실제 검사 결과를 확인해 줘.
$starter-record-decisions 중요한 선택과 근거, 검증 결과, 남은 한계를 정리해 줘.
```

요청 내용과 description에 따라 자동 선택될 수도 있습니다. `/starter-debug` 같은 임의의 슬래시 명령이 모든 버전에서 동작한다고 가정하지 않습니다.

고정된 구버전에서 목록에 없으면 실제 경로를 지정해 읽게 할 수 있습니다.

> 현재 프로젝트의 .agents/skills/starter-debug/SKILL.md를 읽고 그 절차로 연결 문제를 조사해 줘.

이는 문서 지침을 직접 적용하는 대안입니다. 네이티브 스킬 호출이 성공했다는 뜻은 아닙니다. 실행 환경의 버전·허용 도구를 확인하고, 사용 제한이 있는 환경에서 스킬 인식을 위해 Codex 업데이트나 개인 도구 연결을 진행하지 않습니다.

## 기존 프로젝트를 보존하기

설치 도구는 기존 파일을 덮어쓰지 않습니다. 같은 이름의 스킬이 이미 있으면 `EXISTS`로 건너뛰므로 현재 파일의 내용을 읽어 차이를 확인합니다. 기존 AGENTS 지침과 충돌하면 우선순위를 확인하고 적용 가능한 부분만 통합합니다.

단독 진행에서도 같은 스킬을 사용할 수 있습니다. 파일 담당이 나뉜 경우에는 허용된 파일만 수정하고 문서 작성 담당에게 근거를 전달합니다. 외부 게시·제출·배포 권한은 스킬 사용과 별도로 기존 사용자 지시와 환경 규칙을 따릅니다.

## 출처와 확인 범위

원문을 통째로 설치하지 않고 현재 키트의 SPEC·PLAN·VERIFY·EXPLAIN과 비개발자 설명 방식에 맞게 간추려 각색했습니다. 외부 이슈 게시, 필수 병렬 리뷰어, 새 문서 체계 의존성은 제외했습니다. [원문·고정 버전·라이선스](../.agents/skills/THIRD_PARTY_NOTICES.md)를 확인할 수 있습니다.

`python tools/check_kit.py`는 파일·메타데이터·링크·역할 정의의 구조 검사입니다. 실제 Codex의 스킬 발견, 자동 선택, 호출, 과제 기능의 정확성은 따로 확인해야 합니다.

공식 사용 방법: [Codex 스킬 만들기와 사용](https://learn.chatgpt.com/docs/build-skills).
