# 남은 시간에 맞춘 진행 방법

subagent 사용 자체를 시간 절약으로 계산하지 않습니다. 응답 대기와 인계·검토·결과 통합도 실제 작업 시간에 포함합니다. 주 담당이 아래 기준으로 운영 방식을 제안하고 이유와 실제 사용 방식을 PLAN에 기록합니다. 사용자에게 매번 운영 방식을 고르라고 요구하지 않습니다.

## 세 가지 운영 방식

| 방식 | 실제 진행 | 어울리는 작업 | 추가로 드는 시간 |
|---|---|---|---|
| 단독 진행 | 주 담당 한 명이 분석→구현→자체 검증→설명 | 작은 수정, 짧은 작업, 서로 강하게 연결된 기능 | 문맥 전달이 적음. 독립 검토는 없음 |
| 역할을 나눠 진행 | 구현 결과가 나오면 다른 담당이 검사하고 설명을 정리 | 중요한 규칙·계산·데이터 처리처럼 확인이 중요한 기능 | 인계·독립 검사·수정 왕복 |
| 독립 작업 병렬 진행 | 서로 겹치지 않는 작업을 동시에 맡기고 주 담당이 합침 | 별도 파일과 합의된 입출력으로 나눌 수 있는 작업 | 분할·조율·통합·통합 후 재검증 |

예를 들어 할 일 목록에서 문구 하나를 바꾸는 것은 단독 진행이 적합합니다. 중복 저장 방지 기능을 만든 뒤 다른 담당이 정상·중복 입력을 확인하는 것은 역할 분담입니다. 합의된 API 형식으로 화면과 계산 모듈을 각각 다른 파일에서 만드는 것은 병렬 진행의 후보입니다.

역할 분담은 순차적으로 진행할 수 있습니다. 모든 역할을 항상 가동할 필요는 없습니다. 단독으로 검사했다면 자기 검토라고 기록하고 독립 검증자가 있었다고 적지 않습니다. subagent를 지원하지 않는 환경에서는 단독으로 같은 구현·검증·기록 절차를 수행합니다.

## 시간표를 잡는 방법

실제 과제 제한과 전체 마감 시각을 함께 확인합니다. 후속 질문·파일 생성·제출 완료 확인이 별도 절차라면 그 시간도 전체 마감 안에 확보합니다. 아래는 **과제 작업 180분이 주어졌다고 가정한 예시**이며 예상 시간이나 공식 배점은 아닙니다.

| 구간 | 예산 | 해당 구간이 끝났을 때 확보할 것 |
|---|---:|---|
| 요구사항·환경 확인·계획 | 30분 | 필수 기능, 완료 기준, 실행 방법, 위험한 가정 |
| 필수 기능 구현 | 90분 | 실행 가능한 최소 결과와 핵심 테스트 |
| 검증·중요 오류 수정 | 35분 | 실제 정상·오류 확인과 남은 문제 |
| 설명·제출 문서 정리 | 15분 | 판단·근거·검증 결과·한계 |
| 파일·저장·제출 확인 | 10분 | 필요한 파일과 제출 완료 상태 |

합계 180분입니다. 응답 대기는 각 구간에 포함하며 이후에 더하는 시간이 아닙니다. 제공되는 실제 제한이 다르면 다시 배분합니다. 설명과 근거는 구현 중 짧게 누적해 마지막에 처음부터 작성하지 않습니다.

## 중간 점검과 방향 전환

- 작은 기능이 끝나거나 예상보다 오래 걸리면 현재 시각·남은 예산·필수 기능 상태를 확인합니다. 시계를 읽을 수 없는 환경에서는 자동 타이머가 있다고 가정하지 않고 사용자가 알려준 시각을 기준으로 기록합니다.
- 구현 구간이 소진되면 선택 기능과 큰 구조 변경을 멈추고 필수 오류 수정에 집중합니다. 검증·문서·제출 예산을 모두 구현에 쓰지 않습니다.
- 병렬로 나눌 때는 파일 담당·공유 형식·선행 조건·통합 담당을 먼저 정합니다. 같은 파일 동시 수정, 아직 바뀌는 코드의 반복 검토, 너무 작은 일의 위임을 피합니다.
- AI가 작업하는 동안 사용자는 이미 안정된 결과의 기능 확인, 요구사항·제출 파일 목록 확인을 할 수 있습니다. AI가 수정 중인 파일을 함께 편집하거나 같은 명령을 중복 실행하지 않습니다.
- 응답 지연, 승인 대기, 명령 실행 중, 모델·API 실패를 구분합니다. 실행이 계속되는지 확인하기 전에 같은 긴 요청이나 서버 실행을 중복하지 않습니다.
- 플랫폼 오류는 환경에서 제공하는 신고 절차를 따르고 시각·증상을 남깁니다. 지연이 자동으로 보정되거나 시간이 연장된다고 가정하지 않습니다.

이 안내는 시간 예산과 작업 순서에 관한 지침입니다. 백그라운드 타이머·알림·상시 감시 프로그램을 설치하지 않습니다. 스킬과 역할 사용법은 [스킬 안내](SKILLS.md), [역할 대체 안내](../prompts/ROLE_FALLBACK.md)를 참고합니다.
