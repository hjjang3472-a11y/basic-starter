# 결과물 폴더 안내

`outputs/`는 프로그램을 실행해서 생성한 계산 결과·보고서 등의 파일을 둘 수 있는 공간입니다. 현재는 안내 파일만 있으며 실제 결과물은 아직 없습니다. 이 폴더 자체가 결과를 생성하지는 않습니다.

기존 프로젝트가 결과물 저장 위치를 정해 두었다면 그 위치를 사용하고 실제 결과 폴더의 README를 갱신합니다. 이 양식 때문에 기존 결과물을 이동하거나 `outputs/`를 강제로 만들 필요는 없습니다.

## 현재 파일과 확인 방법

경로는 프로젝트 루트를 기준으로 적었습니다. 현재 실제로 존재하는 파일만 나열합니다.

| 경로 | 무슨 결과인가 | 생성 명령 또는 담당 코드 | 확인 방법 |
|---|---|---|---|
| `outputs/README.md` | 결과 파일의 의미와 생성·확인 방법을 설명하는 안내 문서입니다. 결과물은 아닙니다. | 생성 명령 없음. 구현 담당이 작업 내용에 맞춰 갱신합니다. | 이 문서의 목록과 실제 폴더 내용을 비교합니다. |
| `outputs/.gitkeep` | Git에 이 폴더를 남기기 위한 자리 표시입니다. 결과물은 아닙니다. | 생성 명령 없음. 실행 코드도 없습니다. | 파일의 존재를 확인합니다. |

## 결과물이 생기면 갱신하는 방법

- 구현 담당은 할당된 결과 파일을 추가·변경·삭제한 작업 단위가 끝날 때 이 목록도 함께 갱신합니다.
- 각 결과물의 용도, 실제 생성 명령 또는 담당 코드, 내용을 확인하는 방법을 적습니다. 재생성 방법이 없거나 확인하지 못했으면 그 상태를 표시합니다.
- 파일 이름·저장 위치·형식이 바뀌면 설명도 수정합니다. 삭제한 파일을 현재 결과물 목록에 계속 남기지 않습니다.
- 아직 생성하지 않은 결과 파일과 예상 수치를 생성 완료된 것처럼 적지 않습니다.
- 결과가 반복 실행으로 바뀌는지, 입력 데이터가 무엇인지 등 재현에 필요한 정보는 민감값을 제외하고 기록합니다.
- 검증한 수치·판정의 근거는 `docs/VERIFY.md` 역할의 문서와 연결합니다. 확인 없이 결과가 정확하다고 단정하지 않습니다.

## Git 저장 범위

현재 `.gitignore`는 이 폴더의 생성물을 기본적으로 Git에서 제외합니다. 이 README와 `.gitkeep`만 예외로 추적할 수 있습니다. 결과물이 생겼다고 GitHub에 자동 저장되지는 않습니다.

필요한 결과물을 공개하거나 제출할 때는 프로젝트의 규칙과 파일 내용을 확인합니다. 개인정보·비밀값·공개 권한이 없는 데이터는 문서나 저장소에 복사하지 않습니다. 다른 담당과 같은 README를 동시에 수정하지 않습니다.
